SCENE / KITCHEN 11語

台所・食卓

食卓では、同じ音でも指す物がはっきりすると意味がつかめます。「こわい」は餅の硬さ、「じゅるい」はみかんの汁気というように、何を評しているかが手掛かりです。「あんも」「おっしー」は料理の名前として、「こさえる」は作る動作として読んでみましょう。

おっしー味噌汁

汁物一般に広げず、この辞典では味噌汁として扱います。具の名を添えた食卓の場面で読めます。

おっしーを、よそって。
標準語：味噌汁をよそって。

3つの例文・絵札・資料を読む →
あんも餅

餅を指す作例です。郡誌の「あんもう」と現在の辞典見出し「あんも」は、資料欄で表記を区別しています。

あんもを、焼く。
標準語：餅を焼く。

3つの例文・絵札・資料を読む →
こわい（食べ物などが）硬い

食べ物をかむ場面では硬さを表します。怖い話を聞いた場面なら、恐怖の「こわい」も考えられます。

この餅は、こわい。
標準語：この餅は硬い。

3つの例文・絵札・資料を読む →
ちんちん（お湯などが）とても熱いこと

湯や容器の熱さを表す作例です。触って確かめるよう勧める文ではなく、場面から意味を読みます。

やかんが、ちんちんだ。
標準語：やかんがとても熱い。

3つの例文・絵札・資料を読む →
じゅるい水気が多い、汁気が多い

道と食べ物で標準語訳を変えます。水気が多い点は共通でも、それを良いと感じるかは場面次第です。

雨で庭が、じゅるい。
標準語：雨で庭がぬかるんでいる。

3つの例文・絵札・資料を読む →
こさえる作る、こしらえる

料理にも物作りにも使う作例です。遠州以外の話しことばにも見られるため、遠州だけの専用語とはしません。

夕飯を、こさえる。
標準語：夕飯を作る。

3つの例文・絵札・資料を読む →
こずむ（粉や沈殿物が）底にたまる、沈む

液体の底に沈んだ状態を読む作例です。物を高く積み上げることと同じにしません。

粉が瓶の底に、こずんだ。
標準語：粉が瓶の底にたまった。

3つの例文・絵札・資料を読む →
かあばるこびりつく

物の表面に付いて離れにくい状態です。何がどこに付いたのかを一緒に示すと理解しやすくなります。

鍋に、かあばっている。
標準語：鍋にこびりついている。

3つの例文・絵札・資料を読む →
がんきめそらまめ

作物の呼び名です。似た形の豆をすべて同じにせず、標準語のそらまめに対応させます。

がんきめを、皿に盛る。
標準語：そらまめを皿に盛る。

3つの例文・絵札・資料を読む →
ながらみダンベイキサゴ

貝の呼び名です。食卓での名前と生物の名前を対応させ、ほかの巻き貝まで同じものとしないようにします。

ながらみを、皿に盛る。
標準語：ダンベイキサゴを皿に盛る。

3つの例文・絵札・資料を読む →
さら〜ごと、〜全部

名詞に続いて含める範囲を広げます。「さら」という器の名前ではなく、皮や袋も含む言い方です。

皮さら食べる。
標準語：皮ごと食べる。

SCENE / WEATHER 6語

天気・光・道

雨が降ったという天気の話と、道がぬかるんだという状態の話を分けるコースです。「あまけ」から「じゅるい」、さらに足がはまる「いぼる」へ進むと、ひとつの場面を違う観点のことばで説明できます。まぶしさと蒸し暑さも同じ意味にはしません。

あまけ雨天

天気の状態を指す名詞として読みます。雨の強さや将来の予報まで、この一語で分かるわけではありません。

今日は、あまけだ。
標準語：今日は雨天だ。

3つの例文・絵札・資料を読む →
ひずるしいまぶしい

光の強さを感じる場面です。「暑い」とは別なので、冬の日差しをまぶしく感じる説明にも使えます。

西日が、ひずるしい。
標準語：西日がまぶしい。

3つの例文・絵札・資料を読む →
いきれる蒸し暑さにまいる、むっとする

蒸した空気を感じる場面です。「生きられる」という可能表現とは、この文では別の語です。

部屋が蒸して、いきれる。
標準語：部屋が蒸し暑くてまいる。

3つの例文・絵札・資料を読む →
じゅるい水気が多い、汁気が多い

道と食べ物で標準語訳を変えます。水気が多い点は共通でも、それを良いと感じるかは場面次第です。

雨で庭が、じゅるい。
標準語：雨で庭がぬかるんでいる。

3つの例文・絵札・資料を読む →
いぼるぬかるみなどに足を取られてはまる、めり込む

ぬかるみに取られるのは足や靴です。「じゅるい」は道の状態、「いぼる」はそこではまる動きです。

田んぼで足が、いぼる。
標準語：田んぼで足がぬかるみにはまる。

3つの例文・絵札・資料を読む →
だもんで〜だから、〜なので

名詞のあとは「だもんで」、形容詞のあとは「もんで」となる作例です。理由と、そのあとの行動を結びます。

今日は雨だもんで、家にいる。
標準語：今日は雨だから家にいる。

SCENE / HOME 12語

家・庭・片付け

「おおえ」と「おおど」は音が似ていますが、屋内の座敷と家の前の場所という違いがあります。場所を確かめてから、「ご」「はいぼ」「ごんど」など片付ける対象を読み分けます。「うっちゃる」は処分と放置で訳が変わるため、作例を比較してください。

おおえ座敷

家の中の場所を表す語です。家の前の広い場所である「おおど」と比べると位置の違いが分かります。

おおえに、座布団を並べる。
標準語：座敷に座布団を並べる。

3つの例文・絵札・資料を読む →
おおど家の前の広い場所

屋内の座敷を指す「おおえ」と区別します。現代の住所で決まった施設名になる語ではありません。

おおどに、皆が集まる。
標準語：家の前の広い場所に皆が集まる。

3つの例文・絵札・資料を読む →
くろ端、隅、へり

色ではなく位置を表します。机や道など、何の端かを示すと同じ音の「黒」と混同しにくくなります。

机のくろに、置いて。
標準語：机の端に置いて。

3つの例文・絵札・資料を読む →
あいさ間、すきま

二つの物の間を表します。「どことどこの間か」を添えると、狭いすきまの位置も伝えやすくなります。

箱のあいさに、紙がある。
標準語：箱の間に紙がある。

3つの例文・絵札・資料を読む →
らんごく散らかったり、混乱したりしている状態

物が散らかった状態を述べます。何がどこで乱れているかを示すと、人への非難だけにならず具体的です。

机の上が、らんごくだ。
標準語：机の上が散らかっている。

3つの例文・絵札・資料を読む →
ごんどごみ、くず

掃除で集めるごみやくずの呼び名です。処分方法までは語に含まれず、地域の分別案内とは別です。

床のごんどを、集める。
標準語：床のごみを集める。

3つの例文・絵札・資料を読む →
ご枯れた松の葉

一文字なので誤読しやすい語です。数の五や語尾ではなく、庭や松の葉の話として読めるか確認します。

庭の、ごを集める。
標準語：庭の枯れた松の葉を集める。

3つの例文・絵札・資料を読む →
はいぼ灰

燃えたあとに残る灰です。「ひぼ」はひもで、音が近くても指す物は異なります。

かまどの、はいぼを片付ける。
標準語：かまどの灰を片付ける。

3つの例文・絵札・資料を読む →
ほそばイヌマキ（犬槙）

この辞典ではイヌマキの呼び名です。葉が細い植物すべてを「ほそば」と判定できるわけではありません。

ほそばの垣根を、眺める。
標準語：イヌマキの垣根を眺める。

3つの例文・絵札・資料を読む →
うっちゃる捨てる、放っておく

処分と放置の二つの読み方があります。実際に捨てる指示か、触らず置く指示かを確認します。

いらない紙を、うっちゃる。
標準語：いらない紙を捨てる。

3つの例文・絵札・資料を読む →
ほかる捨てる

この辞典では捨てる意味です。「ほかの場所へ移す」と早合点せず、処分対象かを確かめます。

空き箱を、ほかる。
標準語：空き箱を捨てる。

3つの例文・絵札・資料を読む →
ほっぽかすほったらかす、放置する、無視する

放置することへの非難を含む作例です。「ほかる」の処分と違い、置き去りにした状態に目が向きます。

仕事を、ほっぽかした。
標準語：仕事をほったらかした。

SCENE / OUTING 8語

外出・乗り物

出かけるときの「ちゃっと」と「ちょっくら」を比べると、速さと短さの違いが見えます。「けった」「ぽんぽん」は乗り物の呼び名。「とぶ」は地面を走る場面として読めます。家に着いてからの「っち」も含めて、移動の前後を一続きで学びます。

ちゃっと急いで、さっと

行動の速さを伝えます。少量や短時間を表す「ちょっと」を、どの文でも置き換えられるわけではありません。

ちゃっと帰ってくる。
標準語：急いで帰ってくる。

3つの例文・絵札・資料を読む →
ちょっくら少し、ちょっと

少しだけ行動する言い方です。速さを促す「ちゃっと」と比べると、時間や程度の小ささに目が向きます。

ちょっくら、外へ出る。
標準語：少し外へ出る。

3つの例文・絵札・資料を読む →
とぶ走る、走っていく

地面を駆ける場面です。鳥や飛行機の飛行とは、主語と移動場所を見て区別します。

駅まで、とんでいく。
標準語：駅まで走っていく。

3つの例文・絵札・資料を読む →
けった自転車

移動手段の呼び名です。遠州の中でも使う地域に違いがあり、磐田全域の共通呼称とは決めません。

けったで、駅まで行く。
標準語：自転車で駅まで行く。

3つの例文・絵札・資料を読む →
ぽんぽんオートバイ、原動機付自転車

乗り物を指す用法です。手で軽くたたく音の「ぽんぽん」とは、乗る・止まるなどの動詞で見分けます。

ぽんぽんで、出かけた。
標準語：オートバイで出かけた。

3つの例文・絵札・資料を読む →
っち〜のところ、〜の家

人の呼び名に続いて、その人の家を表す場面です。場所か集団かは、後ろの述語から確かめます。

帰りに私っちへ寄って。
標準語：帰りに私の家へ寄って。

3つの例文・絵札・資料を読む →
あっこあそこ

指し示す場所が話し手と聞き手に分かる場面です。文章だけでは場所を特定できないので、位置の説明も添えられます。

あっこに、傘がある。
標準語：あそこに傘がある。

3つの例文・絵札・資料を読む →
在所実家、生まれ育った家やその土地

自分と生まれ育った家・土地との関係を含みます。単に今住んでいる住所を示す語とは限りません。

休みに、在所へ帰る。
標準語：休みに実家へ帰る。

SCENE / WORK 10語

運ぶ・直す・道具

机を「つる」、椅子を「はならかす」、板が「いがむ」というように、動作の主体と対象を確かめるコースです。機械が「つぶれた」ときは外見の変形とは限りません。道具名、動かし方、結果の状態を別に読むことで、作業中の指示が理解しやすくなります。

つる（机などを）持ち上げて運ぶ

物を運ぶ場面です。魚を釣ることや、ひもで上から吊るすこととは、道具や対象が異なります。

机を二人で、つる。
標準語：机を二人で持ち上げて運ぶ。

3つの例文・絵札・資料を読む →
はならかす離す、間を空ける

二つの物の間隔を取る場面です。手から物を離すのか、物同士を離すのかを一緒に伝えます。

椅子を少し、はならかす。
標準語：椅子を少し離す。

3つの例文・絵札・資料を読む →
いのく動く

物にも生き物にも使う作例です。誰かが移動させるのか、自分で動くのかは、主語を確かめます。

この戸は、いのかない。
標準語：この戸は動かない。

3つの例文・絵札・資料を読む →
つぶれる（機械などが）壊れる、動かなくなる

外見が押しつぶされたとは限りません。機能しなくなった話なのか、形の変化なのかを文脈で見ます。

時計が、つぶれた。
標準語：時計が壊れた。

3つの例文・絵札・資料を読む →
いがむ曲がる、ゆがむ

形の曲がりを述べる作例です。何がどちらへ曲がったのかを見ると、物の状態が具体的になります。

板が、いがんでいる。
標準語：板がゆがんでいる。

3つの例文・絵札・資料を読む →
せんひき定規、物差し

道具の名前として使います。線を引く動作の説明と、物としての定規の呼び名を区別しましょう。

せんひきで、線を引く。
標準語：定規で線を引く。

3つの例文・絵札・資料を読む →
ひぼひも（紐）

結ぶ、縛るといった動作と組み合わせると意味が分かります。「ひも」との音の違いを比べられます。

ひぼを、結ぶ。
標準語：ひもを結ぶ。

3つの例文・絵札・資料を読む →
もじかるからまる、もつれる

細長い物同士がからむ場面です。結び目を作る「結ぶ」と違い、意図せずほどきにくくなる様子を示します。

ひもが、もじかった。
標準語：ひもがからまった。

3つの例文・絵札・資料を読む →
てんだい手伝い

手助けすることを表します。「てんこちょ」の上の位置とは音が似ていても別の語です。

片付けの、てんだいをする。
標準語：片付けの手伝いをする。

3つの例文・絵札・資料を読む →
まめったいまめだ、労をいとわずよく働く、こまめだ

手間を惜しまない様子を表します。豆があるという話ではなく、行動のこまめさが手掛かりです。

毎朝掃除をする、まめったい人だ。
標準語：毎朝掃除をするこまめな人だ。

SCENE / BODY 10語

体・身なり・感覚

「えらい」は体のつらさ、「おおぼったい」は重く腫れぼったい感じを表す作例です。部位の「ねち」「舌べろ」、身なりの「やぶせったい」も並べました。これらは日常語の意味を学ぶための項目で、症状の原因や治療を判断する情報ではありません。

えらい疲れた、しんどい

ここでは体のつらさです。「えらい先生」のような評価の意味と、文脈を見て区別します。

坂を上って、えらい。
標準語：坂を上ってしんどい。

SCENE / GRAMMAR 16語

語尾・理由・誘い

「だら」は推量や確認、「だに」は情報を知らせる文末の作例です。「まい」は相手を誘い、「ない」は促す場合があります。標準語の否定形と同じ文字が現れても、文の働きが変わります。声の調子や地域差もあるので、文字列だけで唯一の正解と決めません。

だら〜だろう、〜でしょう

相手も知っていそうなことを確かめる語尾。断定して知らせる「だに」と区別します。

明日も休みだら。
標準語：明日も休みでしょう。

3つの例文・絵札・資料を読む →
ずら〜だろう

推量の言い方です。「いたずら」の途中にある文字まで、語尾の「ずら」として切り分けません。

もうすぐ着くずら。
標準語：もうすぐ着くだろう。

3つの例文・絵札・資料を読む →
ら〜だろう、〜でしょ

「来る」「熱い」のあとで確認します。一文字だけで覚えず、前に付く述語と一緒に読みましょう。

明日も来るら。
標準語：明日も来るでしょう。

3つの例文・絵札・資料を読む →
だに〜だよ、〜なんだよ

文末で情報を知らせる使い方です。文中で逆接になる用法と同じ訳を当てないようにします。

これは私の傘だに。
標準語：これは私の傘だよ。

3つの例文・絵札・資料を読む →
に〜よ、〜ね

行き先を示す助詞の「に」とは別です。「家に帰るに」なら最後の「に」が知らせる語尾です。

先に帰るに。
標準語：先に帰るよ。

3つの例文・絵札・資料を読む →
だもんで〜だから、〜なので

名詞のあとは「だもんで」、形容詞のあとは「もんで」となる作例です。理由と、そのあとの行動を結びます。

今日は雨だもんで、家にいる。
標準語：今日は雨だから家にいる。

3つの例文・絵札・資料を読む →
だで〜だから

理由を示す語尾です。名詞のあとは「だで」、動詞のあとは「で」という形の違いを比べます。

今日は休みだで、家にいる。
標準語：今日は休みだから家にいる。

3つの例文・絵札・資料を読む →
まい〜しよう、〜しようじゃないか

相手を誘う作例です。標準語の「行くまい」のような否定の決意とは、前に付く形を見て区別します。

一緒に、帰らまい。
標準語：一緒に帰ろう。

3つの例文・絵札・資料を読む →
ない〜しなさい

この二文の「ない」は否定ではなく促しです。「書かない」「起きない」という標準語と文字が重なる点に注意します。

ここに、書きない。
標準語：ここに書きなさい。

3つの例文・絵札・資料を読む →
ごう〜してごらん

試してみるよう促すまとまりです。「ごう」だけではなく「てごう」の形で覚えると使いどころが見えます。

この絵を、見てごう。
標準語：この絵を見てごらん。

3つの例文・絵札・資料を読む →
け〜か

尋ねる側の語尾として読みます。声の調子によっても印象が変わるので、常に丁寧語になるわけではありません。

明日も来るけ。
標準語：明日も来るの。

3つの例文・絵札・資料を読む →

前後で対照になる内容を結びます。「けんが」の音だけで、けんかの意味と取り違えないようにします。

標準語：行きたいけれど時間がない。

3つの例文・絵札・資料を読む →

過去にしなかったことを表す用法です。「これは何だ」という疑問の「なんだ」とは、前の動詞が異なります。

標準語：昨日は行かなかった。

進行中と完了後の状態の二つを読めます。遠州内にも地域差があり、どの地域でも同じ形に統一しません。

標準語：庭で待っている。

名称を尋ねる場合と、話の内容を引用する場合があります。「という」に戻すと文の組み立てが見えます。

相手と認識を確かめる場面です。「じゃんか」と置き換えると念押しの感じが変わり得ます。

標準語：この前も会ったよね。

SCENE / AMOUNT 9語

「えいかん」「もっこ」は量の多さを、「ど」「ばか」「がんこ」は程度を強める用法として比較できます。「さら」は何を含めるかを広げる語です。どれも数字で個数を指定する表現ではなく、話し手がどう捉えたかを読む手掛かりになります。

えいかんたくさん、いっぱい

もっこたくさん

皿に、芋がもっこある。

標準語：この芋はとてもおいしい。

SCENE / PLAY 11語

遊び・動き・注意

追いかける、捕まえる、ふざけるといった動きを比べます。とくに「おどける」はこの辞典では驚く意味で、標準語の感覚とずれます。「ちょうける」と並べると違いが見えます。強い動作の語も、行為を勧めるためではなく、意味を読み取るために学びます。

ぼっかける追う、追いかける

追う側と追われる側を分けて読みます。受け身の「ぼっかけられる」なら、自分が追われる側です。

犬がボールを、ぼっかける。
標準語：犬がボールを追いかける。

3つの例文・絵札・資料を読む →
とんます捕まえる

虫などを捕獲する動作です。捕まえた結果なのか、これから捕まえる話なのかは語尾で変わります。

庭で虫を、とんます。
標準語：庭で虫を捕まえる。

3つの例文・絵札・資料を読む →
ちょうけるふざける、おどける

この語はふざける意味です。見出しが似る「おどける」は本辞典では驚く意味なので、別に比較します。

人の前で、ちょうける。
標準語：人の前でふざける。

3つの例文・絵札・資料を読む →

標準語の「おどける」と意味がずれる重要な語です。人を笑わせる「ちょうける」と並べると違いが見えます。

大きな音に、おどけた。
標準語：大きな音にびっくりした。

3つの例文・絵札・資料を読む →
ちょびちょびするふざける、調子に乗る

ちょびちょびして、話を聞かない。

SCENE / SIMILAR 14語

似た音・標準語との違い

同じ文字でも意味が違う語、よく似た音で別の物を指す語を集めました。「いみ」はひび、「こわい」は食べ物の硬さという作例があります。一語だけで即答するより、対象物と動詞を手掛かりに読み、複数の解釈が残るときは相手に確かめる練習に向きます。

いみ陶磁器などのひび、ひび割れ

言葉の「意味」ではなく物のひびです。陶磁器に加えガラスの記録もあり、対象物を添えて読みます。

茶わんに、いみがある。
標準語：茶わんにひびがある。

3つの例文・絵札・資料を読む →
こわい（食べ物などが）硬い

食べ物をかむ場面では硬さを表します。怖い話を聞いた場面なら、恐怖の「こわい」も考えられます。

この餅は、こわい。
標準語：この餅は硬い。

えらい疲れた、しんどい

ここでは体のつらさです。「えらい先生」のような評価の意味と、文脈を見て区別します。

標準語：坂を上ってしんどい。

標準語の「おどける」と意味がずれる重要な語です。人を笑わせる「ちょうける」と並べると違いが見えます。

標準語：大きな音にびっくりした。

標準語：人の前でふざける。

標準語：この絵を見てごらん。
