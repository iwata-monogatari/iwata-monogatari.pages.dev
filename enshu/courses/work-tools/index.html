運ぶ・直す・道具

机を「つる」、椅子を「はならかす」、板が「いがむ」というように、動作の主体と対象を確かめるコースです。機械が「つぶれた」ときは外見の変形とは限りません。道具名、動かし方、結果の状態を別に読むことで、作業中の指示が理解しやすくなります。

2つの会話で、使い方を読む

掲載語の意味に基づく編集部の作例です。実際の発話の引用ではありません。

机を動かす前に

A

この机、二人でつるに。

標準語：この机を、二人で持って運ぶよ。

B

ひぼが引っ掛かっとるで、先にはならかして。

標準語：ひもが引っ掛かっているから、先に離して。

ここでの「つる」は持って運ぶ動作。物が引っ掛かったときは「はならかす」で先に離すことを伝えます。

つるにひぼはならかすとる

板の状態を確かめる

A

この板、いがんどるに。

標準語：この板は、ゆがんでいるよ。

B

無理に押すとつぶれるで、向きを見直すか。

標準語：無理に押すと壊れるから、向きを見直そうか。

「いがむ」は形のゆがみ。「つぶれる」は、この場面では壊れることを表し、物の状態を分けます。

いがむとるにつぶれる

1921年の資料から、4語

原表記と記録地を付けています。文は意味を学ぶための置換作例です。

おかぶ

一語で読む ↗

1921年 / 袋井町 / 1244頁・原表記

おかぼ。

この写真は、おかぶの畑だ。

標準語：この写真は、陸稲の畑だ。

残り2作例・資料を読む

原注は陸稲です。稲全般ではなく、おかぼを指す記録として、水田の稲との語の範囲を分けて読みます。

畑の、おかぶを見る。

標準語：畑の、陸稲を見る。

資料の絵に、おかぶが描かれている。

標準語：資料の絵に、陸稲が描かれている。
