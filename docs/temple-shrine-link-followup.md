# 寺社リンクの積み残し ── ATAWI TEMPLE / SHRINE 側への申し送り

`tools/link_temple_shrine.py` で磐田物語の全ページに寺社リンクを入れた際（2026年8月13日）、
**磐田物語の本文には何度も出てくるのに、ATAWI TEMPLE / ATAWI SHRINE に個別ページが無いためリンクできなかった寺社**を記録する。
リンク先が存在しないだけなので、先方に個別ページができれば
`data/temple-shrine-links.manual.json` を触らずとも、マスター更新 → `tools/build_temple_shrine_links.py` →
`tools/link_temple_shrine.py` の再実行だけで自動的にリンクが張られる。

## 磐田物語側に残る判断待ち

`docs/temple-shrine-link-report.md`「名前が出てもリンクしなかった寺社」の節を参照。
市内に同名が複数あり、本文の近くに大字名が出ていないためリンクを見送った107件がある。
人手で確定できるものは `data/temple-shrine-links.manual.json` の `page_hints` に追記する。

とくに次の2つは、データ側の限界で機械的には決められない。

- **諏訪神社（富里・匂坂西下組）** … `suwa-tomisato` と `suwa-tomisato-2` がどちらも大字「富里」で、
  マスターの情報だけでは大めし祭りの社がどちらか決まらない（t030・oishi-ronko/083 の計20件）。
- **六所神社** … f023〜f028 と oishi-ronko/204 ほかに出るのは提供PDFのファイル名「六所神社の祭り.pdf」で、
  記事本文は同じ社を「六社神社」（福田）と表記している。市内7社の六所神社のどれでもないため、あえてリンクしていない。
