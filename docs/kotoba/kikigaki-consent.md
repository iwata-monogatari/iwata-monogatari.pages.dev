# 磐田のことば 聞き書き 同意書（ひな形）

遠州弁辞典（/c006）の「聞き書き」のための同意書のひな形。印刷して、聞き書きの前に話し手と一緒に読み、記入してもらう。
話し手の控えと磐田物語の保管用に、2部作る。原本は紙で保管し、スキャンをリポジトリや公開サイトに置かない。

---

## 磐田のことば 聞き書きへのご協力のお願い

磐田物語（運営：大石浩之）は、磐田で話されてきたことばを記録し、次の世代へ残すため、聞き書きをお願いしています。
いただいたお話は、遠州弁辞典（https://iwata-monogatari.net/c006）と関連記事で紹介します。

### 1. 聞き書きの内容

- 遠州弁かるたの読み札を読んでいただき、「この言い方をするか」「自分ならどう言うか」をうかがいます。
- 時間は30分ほどです。録音をしてよいかは、下の欄で選んでください。
- 途中でやめても、答えたくない質問に答えなくてもかまいません。

### 2. 公開のしかた（話し手が選んでください）

| 項目 | 選択 |
| --- | --- |
| 録音すること | □ 録音してよい　□ 録音しない（メモのみ） |
| 声（音声）を公開すること | □ 5〜10秒程度の短い音声を公開してよい　□ 音声は公開しない |
| お話の文字起こしを公開すること | □ 公開してよい　□ 公開しない |
| 名前の表示 | □ 仮名（例：見付の80代女性）　□ 名字のみ　□ 氏名 |
| 育った地区の表示 | □ 表示してよい（地区名：　　　　　　）　□ 表示しない |
| 年代の表示 | □ 表示してよい（　　代）　□ 表示しない |
| 写真 | □ 撮影・公開しない　□ 手元・後ろ姿など顔の写らない写真のみ可 |

氏名・住所・連絡先は、同意の記録と連絡のためだけに使い、公開しません。

### 3. 取り下げ

公開した後でも、申し出があれば、音声・文字起こし・名前の表示を取り下げます。
連絡先：富士ヶ丘サービス株式会社（大石浩之）　電話 0538-31-3308

### 4. 記入欄

- 聞き書きの日：　　　　年　　月　　日　　場所：
- 話し手のお名前（自署）：
- ご連絡先（任意）：
- 聞き手：

上の内容を確認し、選んだ範囲での記録と公開に同意します。

## 運用メモ（磐田物語側）

- 公開する発話は、辞典では作例とは別の欄に「記録された発話（◯◯地区・◯代）」として載せ、作例と混ぜない。
- 同意の範囲を超える公開をしない。迷ったら公開しない側に倒す。
- 聞き書き1人につき論考記事1本（「◯◯さんのことば」）を目安にする。記事でも同意書の範囲を守る。
- 同意書の原本・録音の原データは、サイトとリポジトリの外で保管する。
