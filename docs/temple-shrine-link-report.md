# 寺社名の自動リンク レポート

`tools/link_temple_shrine.py` の実行結果。対応表は `data/temple-shrine-links.json`、
手作業の調整は `data/temple-shrine-links.manual.json` で行う。

## リンクの付け方

- 同じ寺社へは **h2 セクションごとに1本だけ**リンクする。
  節が変われば張り直すので、長い論考でも「さっきの寺はどれだったか」に戻れる。
  一方、同じ節の中で同じ寺社名が何度出ても2本目以降は張らない
  （2026-08-13の初回導入時は全出現に張っており、7,366本のうち86%が
  同一ページ・同一寺社への重複だった。同日この方式へ変更した）。
- リンク先は ATAWI TEMPLE / ATAWI SHRINE の**個別ページ**のみ。一覧・検索ページへは逃がさない。
- 別タブで開く（`target="_blank" rel="noopener"`）。見た目は `assets/css/temple-shrine-ref.css` で一括管理する。
- リンクを入れない場所: `<head>`、既存の `<a>` の内側、h1、`header`/`footer`/`nav`、
  配信時に中身が差し替わる `section.article-policy[data-common]` と `section.local-property-note[data-common]`、
  `script`/`style`/`svg`。

### 誤リンクを避けるための決まり

- **山号だけの別称は使わない**（「松林山」は松林山古墳、「風祭山」は地名と衝突するため）。
- **長い固有名詞を優先する**（「遠江国分寺跡」を先に取り、内側の「国分寺」では切らない）。
- **直前12文字に市外の地名があれば見送る**（「京都・松尾神社」「浜松・諏訪神社」「愛知県の津島神社」など）。
- **書名・史料名（『』の内側）にはリンクしない**（『国分寺ものがたり』は本の題名であって寺ではない）。
- **直後が「山古墳群」「古墳」「遺跡」「廃寺」ならリンクしない**（新豊院山古墳群は国指定史跡であって寺ではない）。
- **同名の寺社は、すぐ近くに大字名があるときだけ**リンクする（「下太の八王子神社」「中野白山神社」）。
  ページのどこかに地名がある、地区名が近くにある、という程度の根拠では判定しない。
  近くの大字名で決まった社がページ内で1つに揃えば、同じページの残りの出現にも同じ社を当てる。
- それでも決まらないものはリンクしない（下の一覧に残す）。誤リンクより未リンクを選ぶ。
