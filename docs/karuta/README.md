# 遠州弁かるた 絵札の制作手順（/c006）

遠州弁辞典（/c006）の各語の横に飾る「遠州弁かるた」の絵札を作り、辞典に載せるまでの手順。
企画書「遠州弁辞典（c006）拡充企画書」の柱1を実装したもの。

## 制作表

`docs/karuta/c006-karuta-sheet.csv` に、全語の制作指示がある。Excel でそのまま開ける（UTF-8 BOM 付き）。
この表は `node tools/build_c006_dictionary.mjs` が `data/c006-dictionary.json` から生成するので、手で直さない。
場面や alt を直すときは JSON の `karuta.scene`（場面）と `karuta.alt`（任意。省略時は場面から自動生成）を直す。

| 列 | 内容 |
| --- | --- |
| id | 語ID。元画のファイル名にする（例：`aisa.png`） |
| 語・読み・分類 | 辞典の見出し |
| 頭の字 | かるたの角に入れる一文字 |
| 読み札（作例） | 読み札の文。辞典の作例をそのまま使う |
| 絵の場面 | 絵札に描く場面。作例の場面に限る |
| alt | 画像の代替テキスト（辞典に出る） |
| 状態 | 未制作／公開済み（配信ファイルの有無から自動判定） |

## 絵札の仕様

| 項目 | 仕様 |
| --- | --- |
| 元画 | 1200×1600px（3:4）。最小 900×1200px。PNG または JPEG |
| 構成 | 絵の角に頭の字を一文字。語全体の文字は絵に入れない（語を直しても絵を作り直さない） |
| 場面 | 制作表の「絵の場面」。作例にない用法・地域差・人物の特定につながる描写は入れない |
| 背景 | 語の分類に応じて磐田の風景を添えてよい（見付天神・屋台・天竜川・遠州灘の浜・茶畑・槙の生垣など）。実在の個人宅・店名・看板は描かない |
| 画風 | 2026-10-12、依頼者が試作2枚目の「引札風」を選定。全122語を同じ紙色・藍・朱・黄土・緑の石版画調で制作した。佐口行正氏所蔵の実物史料を複製したものではない |
| 配信 | WebP 300×400（一覧用・目安 40KB 以下）と 900×1200（拡大用）。変換ツールが作る |
| 制作表示 | 「絵札：磐田物語」と生成AIを用いた新規制作である旨を表示する。個々のAI生成部分の著作権成立を断定しない |
| 利用条件 | 学校・公民館・図書館・介護施設・地域の集まりなどでの非営利の利用は、出典「磐田物語 遠州弁辞典（https://iwata-monogatari.net/c006）」の明記を条件に申し出不要（2026-10-12 運営者決定）。販売・商品化・有料の講座や催しなど営利の利用は事前相談。佐口行正氏所蔵史料には適用しない |
| 外注・画像生成 | 外注する場合は、上の非営利利用を妨げない契約（磐田物語が著作権または十分な利用許諾を持つ形）にする。画像生成サービスを使う場合は、そのサービスの規約で生成画像を上の条件で公開・配布できることを確かめる |

### 画風の試作（企画書 第0期）

「だら」（dara）「やぶせったい」（yabusettai）「せんひき」（senhiki）「あんも」（anmo）「ちんぷりかえる」（chinpurikaeru）の5語で3案を描き、画風を1つに決める。
決めた画風の説明文を、以下の「共通の画風指定」に書き足し、以後の全語で同じ指定を使う。

### 共通の画風指定（画像生成や外注に渡す文の型）

```text
遠州弁かるたの絵札。縦長3:4。引札風の石版画調。生成りの紙、藍・朱・黄土・淡い緑、細かな紙の質感。現代の身近な暮らしを、親しみやすく描く。
場面：〈制作表の「絵の場面」〉。
左上の角に丸囲みの一文字「〈頭の字〉」。それ以外の文字・看板・ロゴは描かない。
実在の人物・店・家を特定できる描写は避ける。背景はおだやかに、主題の動作がひと目でわかる構図。
```

## 辞典に載せる手順

1. 元画をリポジトリの外のフォルダに、語IDのファイル名で保存する（例：`C:\…\karuta-originals\aisa.png`）。
2. 配信用に変換する。

   ```powershell
   python tools/build_c006_karuta.py --src C:\…\karuta-originals
   ```

   一部だけなら `--only aisa,dara`。寸法や縦横比が合わない元画は変換せずエラーを出す。
3. 辞典を生成する。300px と 900px の両方がそろった語だけ、自動で絵札に切り替わる。

   ```powershell
   node tools/build_c006_dictionary.mjs
   ```

4. 検査する（`npm run build` と `node --test tests/c006-*.test.*` でも走る）。

   ```powershell
   python tools/build_c006_karuta.py --check
   node tools/build_c006_dictionary.mjs --check
   ```

5. c006 の更新履歴に「絵札◯語を追加」と書き、通常の手順（check-live-sync → build → guard → Git push）で公開する。

## 運用のきまり

- 語を辞典に追加するときは、`karuta.scene` も同時に書く（生成ツールが空欄を止める）。
- 絵札の場面は作例に従う。絵を描くために作例を変えるときは、作例が編集部の作例である旨の注記を保つ。
- 2026-10-12に122語の制作とOGP差し替えを完了。元画は1088×1448px以上で、変換ツールの最小寸法を満たす。配信は300×400と900×1200の2種。
- 元画（PNG）はリポジトリに入れない。配信用 WebP だけを `assets/karuta/c006/` に置く。

## 印刷用PDF

`python tools/build_c006_print.py` で `downloads/enshu-karuta-122.pdf` を生成する。PillowとReportLab、游ゴシックのフォントファイルが必要。別の環境では `--font` と `--bold-font` に日本語TrueTypeフォントを指定する。

A4縦42頁（使い方1頁＋122組）、片面、実際のサイズ100％。札は60×80mm。左が絵札、右が作例・標準語訳を添えた読み札。絵は約254dpiで埋め込み、PDFは約19.3MB。本文のはみ出しは生成時に検査し、生成後は全ページを画像化して確認する。辞典の語・作例を更新したらPDFも再生成する。
